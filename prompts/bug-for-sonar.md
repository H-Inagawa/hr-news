# SonarQube検証用バグ仕様（改訂版）

このファイルは、SonarQubeの脆弱性検知機能および解析機能をテストするために埋め込むバグと脆弱性の内容を定義します。

## 意図的に含める問題

### 1. セキュリティ脆弱性（CVE類似）
- **パス・トラバーサル (Path Traversal)**: ユーザー入力をファイルパスに使用し、任意のファイルを読み込める状態。
- **コマンド・インジェクション (Command Injection)**: `child_process.exec` 等にユーザー入力を渡し、OSコマンドを実行できる状態。
- **情報漏洩 (Information Exposure)**: エラーレスポンスに `process.env` やスタックトレースを含める不適切なエラーハンドリング。
- **クロスサイトスクリプティング (XSS)**: `dangerouslySetInnerHTML` を使用し、サニタイズされていない入力をレンダリングする状態。
- **安全でないストレージ**: 機密情報（APIキー等）をローカルストレージに平文で保存。

### 2. バグ（Bug）
- **null / undefined チェック不足**: オブジェクトのプロパティ参照時のチェック欠如。
- **配列の範囲外アクセス**: 固定インデックスでのアクセスや境界条件の誤り。
- **非同期処理の不備**: `await` の付け忘れによる意図しない動作。
- **例外処理の欠如**: try-catch で囲まれていない危険な処理。

### 3. コードスメル（Code Smell）
- **重複コード**: 同様のロジック（設定読み込み等）の複数箇所へのコピペ。
- **巨大な関数**: 1関数が50行を超える、複数の責務を持った関数。
- **深いネスト**: if/else や ternary の多重ネスト（3階層以上）。
- **マジックナンバー**: 意味の不明な数値の直書き。
- **未使用の変数/インポート**: 定義されているが使われていないコード。

## 出力要件
- **実行可能なコード**: バグを含みつつも、アプリケーションとして起動・動作すること。
- **あえて問題を残すこと**: SonarQubeで検知させるため、修正は行わない。
- **コメントの付与**: 埋め込んだ箇所の意図がわかるよう、日本語でコメントを入れること。
