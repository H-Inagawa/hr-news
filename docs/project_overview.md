# プロジェクト概要

---

## プロジェクト概要

**hr-news** は、Google News RSS からカテゴリ別にニュースを取得し、内容を要約・編集したうえで Slack チャンネルへ投稿する Web アプリケーションです。労務関連や AI 関連など、社内で注目すべきトピックを効率的に収集・共有することを目的としています。

---

## 背景

小規模な事業者では、従業員の役割を明確に定めていないことが多く、労務管理・社内広報などの活動が後回しにされがちです。

本プロジェクトは、そのような活動のための情報収集・要約を低負荷で実現するために立ち上げました。Google News RSS から関連ニュースを取得し、要約・編集したうえで Slack 等の社内 SNS に投稿することで、専任担当者がいなくても社内への情報共有を継続しやすくすることを目指しています。

---

## 目的

コードおよび既存 README から判断できる目的は以下のとおりです。

- カテゴリ別（労務、AI 関連など）に最新ニュースを RSS から取得する
- 取得した記事を要約し、カテゴリとの関連性を簡易検証する
- 要約内容を手動で編集できる
- 編集済み要約を Slack の特定チャンネルへ投稿する

---

## 想定利用者

| 利用者 | 説明 | 主な利用シーン |
|--------|------|---------------|
| 小規模事業者の社内担当者 | 労務・広報などを兼務し、社内 SNS への情報発信を担うユーザー | カテゴリ選択、ニュース取得、要約編集、Slack 投稿 |

専任の広報・労務担当がおらず、日常業務の合間に情報収集・共有を行う利用を想定しています。

現時点では認証機能は未実装ですが、試験運用段階のためであり、今後追加予定です（[docs/decision_log.md](decision_log.md) 参照）。

---

## 主要機能

| 機能 | 概要 |
|------|------|
| カテゴリ一覧取得 | `search-config.json` で定義されたカテゴリをプルダウン表示 |
| ニュース一覧取得 | Google News RSS からカテゴリ・追加キーワードに基づき取得 |
| 要約作成 | RSS スニペットを 200 文字程度に切り出し、関連性を検証 |
| 要約編集 | テキストエリアで要約内容を手動編集 |
| Slack 投稿 | Incoming Webhook 経由で要約を Slack に送信 |

詳細は [docs/features/](features/) を参照。

---

## システムスコープ

本システムが担う範囲（コードから確認できるもの）:

- Google News RSS からのニュース取得（3 か月以内、日付降順）
- カテゴリ別検索クエリの動的生成（`search-config.json` ベース）
- 記事内容の簡易要約（文字切り出し）とカテゴリ関連性の警告表示
- 要約の手動編集 UI
- Slack Incoming Webhook への投稿
- 開発環境向け API プロキシ（Vite → Express）

---

## 対象外スコープ

現時点の実装において、以下は対象外とする。

- ユーザー認証・認可（試験運用中のため未実装。将来追加予定）
- ニュース・投稿情報の永続化（アプリ軽量化のため DB 未使用。投稿情報の保存想定なし）
- ニュースの削除機能
- ニュースの新規作成（RSS 外部ソースからの取得のみ）
- AI（LLM）による高度な要約
- 投稿履歴の保存
- 複数 RSS ソースへの対応（Google News RSS のみ）
- ニュースフィルタリング機能の強化
- 本番デプロイ・CI/CD の確定（サンプル構成のみ [docs/system_architecture.md](system_architecture.md) に記載）

## 用語集

| 用語 | 説明 |
|------|------|
| カテゴリ | `search-config.json` で定義されるニュース分類（例: 労務、AI 関連、カテゴリなし） |
| キーワード | カテゴリごとの RSS 検索用 OR 結合キーワード（`keywords`） |
| フィルタ | カテゴリごとの RSS 検索用 OR 結合フィルタ（`filters`） |
| 検証キーワード | 要約時にカテゴリ関連性を判定するためのキーワード（`validationKeywords`） |
| 要約 | RSS スニペットを 200 文字程度に切り出したテキスト。関連性警告・記事リンクを含む場合あり |
| Incoming Webhook | Slack への投稿に使用する Webhook URL（環境変数 `SLACK_WEBHOOK_URL`） |
